20 עמודים של PDF, בלי לשרוף את המכסה

כל עמוד PDF שמעלים לקלוד נכנס פעמיים: גם כטקסט וגם כתמונה. MarkItDown, כלי חינמי של מיקרוסופט, הופך את הקובץ לטקסט נקי לפני שמעלים. הנה איך: בפקודה אחת, או כחיבור לקלוד למחשב. ובסוף, דרך בלי להתקין כלום.

את MarkItDown לא אני בניתי: זה כלי קוד פתוח של מיקרוסופט, ברישיון MIT. הפקודות לקוחות מהמאגר הרשמי, נקרא ב-26.11.2026. לא הרצתי אותן.

מה צריך לפני שמתחילים

  • לפקודה: מחשב עם טרמינל, ו-Python בגרסה 3.10 עד 3.14.
  • לחיבור לקלוד: האפליקציה של Claude למחשב, ותוכנה בשם Docker.
  • לבונוס בסוף: רק חשבון Claude. מתאים גם לתוכנית החינמית.

למה PDF כבד

לפי התיעוד של Anthropic, כל עמוד PDF נשלח גם כטקסט וגם כתמונה של העמוד. הטקסט עולה בערך 1,500 עד 3,000 טוקנים לעמוד, והתמונה עוד עד 1,568. ב-20 עמודים זה בערך 61 עד 91 אלף טוקנים, עוד לפני ששאלתם שאלה.

המספרים האלה מהתיעוד למפתחים (API). ל-claude.ai אין מספר רשמי של כמה זה תופס מהמכסה, ולא מדדתי כמה ההמרה חוסכת.

דרך 1: פקודה אחת עם MarkItDown

הכלי של מיקרוסופט הופך קבצים (PDF, Word, PowerPoint, Excel ועוד) לטקסט עם כותרות, רשימות וטבלאות. את הקובץ שיוצא מעלים לקלוד.

  1. בודקים שיש Python. צריך גרסה 3.10 עד 3.14. אין? מורידים מ-python.org.
    בודקים גרסה
    python3 --version
  2. מתקינים את הכלי.
    התקנה
    pip install 'markitdown[all]'

    במק הפקודה נקראת לפעמים pip3. המאגר ממליץ להתקין בסביבה וירטואלית, כדי שהחבילות לא יתנגשו עם דברים אחרים במחשב.

  3. ממירים. מחליפים את file.pdf בשם הקובץ שלכם.
    המרה
    markitdown file.pdf -o document.md
  4. מעלים לקלוד את document.md במקום ה-PDF.

לא בדקתי איך הוא מסתדר עם מסמך בעברית, ובמיוחד עם טבלאות מימין לשמאל. כדאי להעיף מבט בקובץ שיצא לפני שמעלים.

דרך 2: לחבר אותו לקלוד למחשב

מיקרוסופט מפרסמים גם שרת MCP, כלומר חיבור שדרכו Claude Desktop ממיר קבצים בעצמו. לקלוד למחשב הם ממליצים להריץ אותו ב-Docker.

  1. בונים את הכלי פעם אחת, מתוך המאגר שלהם:
    טרמינל
    git clone https://github.com/microsoft/markitdown.git
cd markitdown/packages/markitdown-mcp
docker build -t markitdown-mcp:latest .
  2. מוסיפים אותו להגדרות של Claude Desktop, בתפריט Claude ← Settings… ← Developer ← Edit Config. נפתח הקובץ claude_desktop_config.json (אם אין, הוא נוצר). מחליפים את /path/to/docs בנתיב המלא של תיקיית המסמכים. רק אותה הוא יוכל לקרוא.
    claude_desktop_config.json
    {
  "mcpServers": {
    "markitdown": {
      "command": "docker",
      "args": [
        "run", "--rm", "-i",
        "-v", "/path/to/docs:/workdir",
        "markitdown-mcp:latest"
      ]
    }
  }
}

    אם כבר יש לכם חיבורים אחרים בקובץ, מוסיפים את "markitdown" בתוך mcpServers הקיים.

  3. סוגרים את Claude Desktop לגמרי ופותחים מחדש, ומבקשים ממנו להמיר קובץ מהתיקייה. בתוך החיבור, התיקייה נקראת /workdir.

בונוס: בלי להתקין כלום

אין טרמינל? אפשר לחסוך חלק מהעומס גם בלי הכלי:

  1. צריכים רק את הטקסט? (חוזה, תקנון, מסמך כתוב) שומרים את הקובץ כ-Word או כקובץ טקסט, ומעלים אותו במקום ה-PDF. לפי דף העזרה של Claude, מסמך שהוא לא PDF נקרא כטקסט בלבד.
  2. או מעתיקים רק את הקטע שצריך ומדביקים אותו בצ'אט, במקום להעלות את כל 20 העמודים.
  3. צריכים את הגרפים, הטבלאות המעוצבות או התמונות? משאירים PDF. בלי התמונה של העמוד קלוד לא רואה אותם.

איך שומרים כ-Word תלוי בתוכנה שפותחת את ה-PDF. בדרך כלל זה "שמירה בשם" או "ייצוא".

מתי לא להמיר

  • הגרפים והתמונות חשובים: משאירים PDF.
  • PDF סרוק (צילום של דף): הכלי לא מוציא ממנו טקסט בלי תוסף זיהוי טקסט, שדורש מפתח של מודל. כאן עדיף להעלות את ה-PDF כמו שהוא.
