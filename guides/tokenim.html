איזה מודל של Claude למה

מתחילים ב-Opus, ועולים ל-Fable רק כשצריך. טבלה בעברית, והפקודות להעתקה.

נכתב לפי התיעוד הרשמי של Anthropic, שנקרא ב-25.11.2026. בסוף יש קישורים למקור.

מה צריך לפני שמתחילים

  • להחלפת מודל בצ'אט: חשבון Claude. אילו מודלים מופיעים בבורר תלוי בתוכנית שלכם.
  • לפקודות: Claude Code מותקן. מדריך ההתקנה כאן.
  • לטריק של היועץ (/advisor): גישה ל-Fable, וגרסה 2.1.321 ומעלה של Claude Code.

⚠️ המחירים בדף הם מחירי API. במנוי זה מחושב אחרת: הכל נספר מול המגבלות של התוכנית.

  • Fable לא כלול במגבלות של Pro, וגם לא במושבים הרגילים של Team ושל Enterprise. שם הוא רץ על קרדיטים. כך כתוב במדריך הרשמי מ-12.11.2026.

הטיפ הרשמי: קודם עוצמה, אחר כך מודל

לפני שעוברים למודל יקר יותר, מעלים את עוצמת החשיבה של המודל שכבר עובד. רק אם זה עדיין לא מספיק, מחליפים מודל. ככה ממליץ המדריך הרשמי.

איך מחליפים מודל

בצ'אט של Claude

  1. ליד כפתור השליחה מופיע שם המודל. לוחצים עליו ובוחרים. מודלים נוספים נמצאים תחת More models.
  2. אפשר להחליף באמצע שיחה. השינוי חל מהתשובה הבאה.
  3. לעוצמת חשיבה: לוחצים על שם המודל ← Effort ← בוחרים רמה. הרמה המומלצת מסומנת Default.

השמות כאן לקוחים מדף העזרה באנגלית. אצלכם הם עשויים להופיע בעברית.

ב-Claude Code

פותח את בורר המודלים
/model
  • בבורר, Enter שומר את הבחירה לפעמים הבאות, ו-s מחליף רק לשיחה הנוכחית.
  • אפשר גם לכתוב ישר /model sonnet או /model opus.
  • לעוצמת חשיבה: /effort.
  • ליד Fable יכול להופיע Requires usage credits. בפעם הראשונה תתבקשו לאשר שימוש בקרדיטים, או לחזור למודל הקודם.

הטריק מהסרטון: Sonnet עובד, Fable מייעץ ניסיוני

ניסיוני. בתיעוד הרשמי /advisor מסומן ככלי ניסיוני. הוא דורש גישה ל-Fable, את Claude Code בגרסה 2.1.321 ומעלה, וחיבור ישיר ל-Anthropic. עוד לא הרצתי אותו בעצמי.

Sonnet עושה את העבודה, ו-Fable נכנס רק ברגעי החלטה: לפני שבוחרים דרך, כשאותה שגיאה חוזרת, ולפני שמכריזים שהמשימה גמורה. Claude מחליט לבד מתי להתייעץ, ואין הגדרה שמכריחה אותו להתייעץ או מגבילה אותו.

בקלוד קוד, לפי הסדר:

  1. מעבירים את העבודה למודל זול יותר. הבחירה נשמרת גם לשיחות הבאות.
    המודל הראשי: Sonnet
    /model sonnet
  2. מכניסים את Fable כיועץ. /advisor בלי שם פותח רשימה לבחירה. בפעם הראשונה ייתכן שתתבקשו לאשר שימוש ב-Fable פעם אחת, דרך /model fable.
    היועץ: Fable
    /advisor fable
  3. מכבים את היועץ כשלא צריך.
    מכבה את היועץ
    /advisor off
  4. רק לשיחה אחת, בלי לשנות את ההגדרות הקבועות: מפעילים כך את Claude Code מהטרמינל. האפשרות הזאת מופיעה בתיעוד, אבל לא ברשימת העזרה של הפקודה, ויש מקורות שסותרים זה את זה לגביה.
    טרמינל, לשיחה אחת
    claude --model sonnet --advisor fable

היועץ חייב להיות מודל שווה למודל הראשי או חזק ממנו. עם Sonnet כמודל ראשי אפשר לבחור Fable, Opus או Sonnet. אם הגרסה שלכם ישנה, מעדכנים ב-claude update.

וכמה זה חוסך?

אין לי מספר לתת, וגם אין מספר רשמי. כל התייעצות עולה טוקנים של Fable, מעבר לטוקנים של Sonnet: היועץ קורא את כל השיחה ומחויב בתעריף שלו. זה זול יותר רק בהשוואה לעבודה עם Fable לבד, וגם את זה לא מדדתי.
